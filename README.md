# DV_ADSBot
A self-hosted Discord bot that brings live **Derail Valley** railway information and selected dispatcher controls into your server through the **Advanced Dispatcher System (ADS)** web API.  The bot uses ADS's authenticated HTTP API and WebSocket stream directly—there is no screen scraping. It provides slash commands, live autocomplete, role-based access, an automatically refreshed dispatch board, and optional connection/event alerts.  > [!IMPORTANT] > This is a companion application, not a standalone in-game mod. Derail Valley and the Advanced Dispatcher System Web Host must be running for live data and controls to be available.
