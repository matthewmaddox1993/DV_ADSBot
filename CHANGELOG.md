# Changelog

All notable changes to Derail Valley Discord Dispatcher are documented here.

This project follows [Semantic Versioning](https://semver.org/).

## Unreleased

### Added

- Automatic GitHub version checks and verified updates for source and standalone installations.
- Separate Windows and Linux installation and operating guides.

- Platform-specific documentation in standalone release builds.
- This changelog.

## 1.0.0 - 2026-10-09

### Added

- Initial public release.
- Discord slash commands for trains, players, jobs, signals, blocks, switches, turntables, routes, events, and weather.
- Role-based Viewer, Dispatcher, and Admin permissions.
- Live dispatch board and optional ADS connection/event alerts.
- ADS HTTP and WebSocket integration with reconnect and state resynchronization.
- Windows and Linux x64 standalone build support.
